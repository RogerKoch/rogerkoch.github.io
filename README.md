# rogerkoch.github.io

Öffentliche Seiten (GitHub Pages) für private Tools. Nicht löschen, solange die Tools sie brauchen.

| Seite | Wofür |
|---|---|
| `index.html` | Startseite der Google-OAuth-App **rclone-backup** |
| `datenschutz.html` | Datenschutzerklärung dieser App |

Google verlangt beide Links (plus `rogerkoch.github.io` als autorisierte Domain), damit die App „In Produktion“ sein kann. Ohne das läuft die rclone-Anmeldung alle 7 Tage ab.
Verwendet vom täglichen DB-Backup auf dem Server, siehe RogerKoch/server-infra `docs/3-backup.md`.
